About

This shell adds desktop controls around the preserved chat UI rather than restyling the chat page itself.

  • Uses the same CGI backend and SSE streams as the browser demo.
  • Keeps the app-owned chat page and stylesheet as the source of truth.
  • Stores mode and target URL in backend UI prefs instead of browser-only storage.
  • Leaves the original `/pages/chat.html` demo page untouched until you approve removing it.
